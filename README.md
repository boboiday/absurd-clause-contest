A single deadpan terms-of-service clause, buried deep in the fine print: autocorrect suggestions accepted after midnight become the property of the Company — and may be published, performed, or read aloud at the annual meeting.

## Run it

```sh
node main.ts
```

This prints the clause to stdout and writes it to `/output/entry.txt` (190 characters, UTF-8, single line).
